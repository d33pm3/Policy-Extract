# Gold-pack policy

No historical client extraction pack is a gold file, fixture,
regression expected-output, or quality target for this skill.

Earlier engagement drafts were produced before the recall contract.
Using any of them as expected output would lock in the omissions this
skill exists to prevent.

Correct use of a prior pack: historical draft only. Correct proof of
the live skill: run Stages 0–7 on a **new** policy (or the synthetic
smoke corpus in `scripts/smoke_live_skill.py`), then read C1/C3 coverage
ratios — never the raw requirement count.
